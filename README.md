# רחל לסקר - דף נחיתה לביטוח ופנסיה

דף נחיתה סטטי לאתר של רחל לסקר, סוכנת ביטוח ופנסיה.

## מבנה

- `src/pages/` - מקור העמודים (HTML עם שורות include).
- `src/partials/` - חלקים משותפים: `header.html` (ניווט עליון), `footer.html`, `footer-404.html` (וריאנט מקוצר לעמוד 404).
- `build.js` - בילד קטן ללא תלויות שמרכיב את העמודים מחדש לתוך `site/`.
- `site/` - פלט הבילד: קובצי האתר הסטטיים ש-Vercel מגיש. לא עורכים ידנית.
- `vercel.json` - הגדרות הפריסה; Vercel מגיש את `site/`.

## עריכה ובילד

עורכים תמיד ב-`src/` ולא ב-`site/`:

- שינוי ב-header או ב-footer משותף → עורכים את ה-partial ב-`src/partials/` פעם אחת.
- שינוי בעמוד ספציפי → עורכים את העמוד ב-`src/pages/`.

אחרי עריכה מריצים:

```sh
node build.js
```

הבילד מכתיב מחדש את `site/`; מומלץ לוודא ב-`git diff` שהשינוי בפלט תואם את הכוונה.
ה-token `{{current:/path/}}` ב-header מוחלף אוטומטית ב-`aria-current` לפי מפת העמודים בתוך `build.js` (ערכי "page"/"true" הם וריאציה מכוונת - לא לאחד).

## הרצה מקומית

דרושה התקנת Python 3. מתוך תיקיית הפרויקט:

```sh
cd site
python -m http.server 8000
```

פתחו `http://localhost:8000/` בדפדפן.
