# רחל לסקר - דף נחיתה לביטוח ופנסיה

דף נחיתה סטטי לאתר של רחל לסקר, סוכנת ביטוח ופנסיה.

## מבנה

- `site/` - קובצי האתר הסטטיים (HTML, CSS, JavaScript, תמונות ועמודי שירות).
- `vercel.json` - הגדרות הפריסה; Vercel מגיש את `site/`.

## הרצה מקומית

דרושה התקנת Python 3. מתוך תיקיית הפרויקט:

```sh
cd site
python -m http.server 8000
```

פתחו `http://localhost:8000/` בדפדפן.

## פריסה

Vercel מפריס אוטומטית שינויים שמתמזגים לענף `main`. פתיחת Pull Request יוצרת פריסת Preview לבדיקה לפני המיזוג.
